# 全指令可视化编辑器设计

## 目标

把剧情编辑器的常用指令都变成可读、可点、可插入的行内 chip，让普通作者无需记忆标签语法。普通叙事仍然保持纸本文稿的连续阅读感；源码模式继续作为高级兜底，且不会在切换时格式化或丢失内容。

## 视觉语言

方向是“纸本文稿上的低饱和批注”。chip 只包住指令本身，不包住整行叙事；无阴影卡片墙、无高饱和色块。现有编辑器的宋体正文继续作为主体文字。

亮色主题的文字/边线使用下列基色，chip 背景用同色约 10% 不透明度；暗色主题改用偏亮但不刺眼的文字色和约 20% 不透明度背景，并保持正文对比度。

| 指令类别 | 用途 | 色系 |
| --- | --- | --- |
| 读取剧情状态 | `{金币}`、布尔分支文本 | 苔绿 `#4F7B62` |
| 设置剧情状态 | 赋值、增加、减少、玩家输入 | 青松 `#3F7F7A` |
| 选项 | 选项、条件、效果摘要 | 雾蓝 `#527A9E` |
| 背景 | 召唤背景、背景效果 | 赭灰 `#8B6F57` |
| 物品 | 召唤物品、叠层 | 茶棕 `#947348` |
| 音乐 | 召唤音乐、停止音乐 | 灰酒红 `#8A5B62` |
| 音效 | 召唤音效 | 灰紫 `#726C88` |
| 流程 | 标题、停顿、分割线、剧情块、跳回、随机 | 石墨灰/土黄 |

## 可视化内容模型

`StoryVisualDoc` 扩展为识别全部现有单行指令、素材召唤、剧情块和流程指令。每个节点保留原始 span 与 raw 文本；可视化操作只局部替换该 span。未识别或高级字段显示为只读源码 chip，并提供“在源码模式编辑”，绝不丢弃。

文本内状态读取仍是绿色原子 token。独立状态变化是青绿色摘要 chip。选项保留蓝色可编辑入口、条件与效果摘要；素材和流程指令使用各自颜色与现有 SVG 图标。

## 插入与编辑

可视化编辑顶部提供一个“插入”菜单，包含：剧情状态、选项、背景、物品、叠层、音乐、音效、标题、停顿、分割线、跳转和随机流程指令。插入位置是最近一次可视化光标；没有光标时追加到当前文本节点末尾。

右侧素材库的卡片点击或拖入在可视化模式中走同一插入服务：将相应素材指令插到可视化光标，不要求先切源码模式。剧情状态管理中的“插入到正文”也走同一服务。

## 模式与预览

移除编辑器工具栏中的“分屏”按钮和分屏状态；不再维护左写右渲模式。保留“预览”作为独占编辑主区的阅读预览，打开时隐藏可视化区和源码区；退出预览后恢复此前的编辑模式。试玩保持其现有全屏体验。

## 可访问性与主题

每个 chip 都有文字标签、SVG 图标或 aria-label，颜色不是唯一信息来源。所有 chip 使用主题变量，不在 JS 内硬编码颜色。亮色与暗色分别有前景、背景、边线 token；文字对比度至少达到普通正文可读水平。

## 验收

1. 可视化正文可识别并渲染全部既有常用指令，未知指令不会被改写。
2. 读取状态绿色、设置状态青绿、选项蓝色；四种素材指令颜色不同且低饱和；亮暗主题均清晰。
3. 可视化模式能通过顶部插入菜单和素材库卡片插入内容，不需切换源码模式。
4. 工具栏不再出现分屏，预览只占编辑主区，不与任何编辑区并排或上下分割。
5. 原有全量测试、无损往返和测试版构建通过。
