剧情编辑器 使用文档

互动剧情采用一套原生标记写作，无需任何代码基础。左侧为大纲目录，可快速跳转。

▌新手教程：30 分钟做出你的第一个文字游戏

目标：做一个最简单的互动文字游戏——「你在陌生房间里醒来，要找钥匙逃出去」。

第 1 步

写出第一句剧情

中间的文本框就是我们的剧情编辑器。我们在里面打字即可编写剧情，回车可以换行。换行会在游戏中忠实地还原。

我睁开眼，头顶是一盏忽明忽暗的灯。
身下是冰凉的水泥地。

这就是最基础的"文字游戏"——一行一行出现文字，玩家一行一行看。

!小提示：编辑器会实时自动保存，所以无需进行保存。

第 2 步

加一个背景

首先，我们在右侧的背景库中上传一张背景（也可以点击渐变 / 噪波生成器进行生成），然后拖动到文字编辑器中，软件会自动在光标位置增加一行 <召唤背景:图片名称>。<召唤背景> 指令需要独占一行。

<召唤背景:昏暗房间>
我睁开眼，头顶是一盏忽明忽暗的灯。

这个格式写好之后，游戏进行到这一行时，就会在背景显示这张图片了。

!小提示：也可以直接输入 <召唤背景:名称>，即便素材库里没有对应的素材，之后再使用素材待办清单功能补充。

第 3 步

用停顿控制节奏

文字全部一起出来的话，故事就没有节奏感了。这时候就需要用停顿控制节奏。<停顿> = 玩家点一下才会继续。

停顿的按钮放在文字工具箱中，快捷键是 Tab。

<召唤背景:昏暗房间>
我睁开眼，头顶是一盏忽明忽暗的灯。
<停顿>
墙角有扇门，门把手上挂着一把生锈的锁。
第 4 步

让玩家检视物品

<召唤物品:名称> 弹出可检视的 3D 物品界面。和召唤背景类似，需要先上传到物品库中，再拖动到文字编辑器里。（格式特殊，需要用 3D 交互制作器制作）

<召唤物品:生锈钥匙>
我蹲下，从床底摸出一把 [color=#c0c0c0]生锈钥匙[/color]。
第 5 步

做选项分支

选项分支是"互动感"的关键：我们要先引入一个新的概念，叫剧情块。

剧情块位于右侧素材库的「剧情块库」中，点击后可以看到里面已经有一个名为「主剧情」的剧情块。

点击「新建剧情块」，会多出一个名为「新剧情」的剧情块。我们点击「主剧情」和「新剧情」，就能在两个剧情块之间切换。

<选项:"按钮文字",剧情块名>，这个指令将在游戏底部生成按钮。如果需要多个选项，可以在同一行写多个 <选项:"按钮文字",剧情块名> 指令，不要换行。我们将这个指令写入主剧情。

接下来编写分支剧情块的剧情，分支块需要用 <跳回> 收尾，这个指令可以自动返回主剧情我们来的那一行；如果没有写 <跳回>，剧情将在这里结尾。

主剧情块：

我握紧钥匙，走向那扇门。
<选项:"先检查门","检查门剧情块"><选项:"用钥匙开门","开门剧情块">
门后透出一丝光。

检查门剧情块：

门纹丝不动，外面射进来一道光。
<跳回重选>

撞门剧情块：

门被钥匙打开了。逃离成功。

玩家点「先检查门」→ 进入「检查门」块 → 看完跳回主对话继续。

!小提示：剧情块中间可以嵌套剧情块。

第 6 步

配乐与音效

和其他素材一样，音乐和音效可以拖动文件到窗口上传，并拖入文字编辑器添加。<召唤音乐:名称> 可以播放背景音乐，背景音乐会循环播放；<召唤音效:名称> 可以播放音效，与背景音乐不同，音效只会播放一次。

<召唤音乐:低沉弦乐>
我拧动钥匙，锁"咔"地开了。<召唤音效:开锁>
第 7 步

补齐素材

如果你使用了AI编剧功能，或是手写了一些素材召唤指令，但还没有上传相应素材，则会出现「素材待办」按钮，位置在文字编辑器的右上角。点击后可以方便地进行素材补全。

!小提示：先一口气把文本写完（召唤指令里的名字可以随便编），再统一去素材库补素材，效率最高。待办还支持「悬停某行 + 按 Ctrl+V 贴图」快速补齐，详见素材待办。

第 8 步

预览与导出

如果你写了比较多的指令，在文本编辑器中不太直观，则可以打开「👁 预览」或「▥ 分屏」功能，即可实时查看实际游戏中的效果，边看边调。点击画面右上角的「试玩」，可以进行真实游玩来体验游玩效果。

!小提示：文字预览的快捷键是右 Ctrl，游戏试玩的快捷键是 F12。

导出成品：点「导出成品 ▾」→

  • 单 HTML：生成一个文件，直接发给别人就能玩。
  • 标准结构压缩包：图片 / 音频外置为文件，方便你后期替换修改。
  • 工程备份：把整个工程打包（含素材 / 剧情状态 / 关键线索 / 创作设定），用于换设备或跨链接迁移，不含 AI Key。

到这步，你的第一个文字游戏就完成了，恭喜！🎉

▌AI 功能：让 AI 帮你写剧情

编辑器内置 AI 编剧，可以帮你生成、续写或扩写剧本。

前置设置流程：

  1. 首次使用点「AI 编剧」会提示先完成信息补全，本工具暂时仅支持 deepseek，在「设置 → AI编剧 →模型与密钥」里填入你的 API Key 并保存。填写简介（一句话概括整个故事）、大纲（故事具体发展脉络）、世界观（是现代都市？还是古代？或是异世界？）、文风（零度叙事、温馨、冷酷、热血等等）。
  2. 设置完成后关闭设置页面即可，同一项目以后不用重复设置。

使用流程：

  1. 点文字编辑器上方的工具栏「AI」按钮。选择生成模式，补充备注，之后点击「生成」。用户审阅后即可插入正文。
  2. 不满意可点「重新生成」，或直接手动改文字。

AI 写出的初稿建议人工过一遍：检查分支是否闭环（每个分支块都有 <跳回>）、素材名是否齐全。

关键线索提取（AI）

写长篇互动剧情时，伏笔容易前后对不上。编辑器内置了一个 AI「关键线索」提取助手，会通读你的大纲、简介与全部正文，自动梳理出可能影响整体剧情走向的线索（人物特征、未解角色、未使用的物件、隐患……共 9 类），帮你在续写时保持一致。

  • 在设置页：进入「设置 → AI编剧」，找到「关键线索」文本框，点「提取关键线索」按钮。AI 会填入完整线索清单，并附一段变更说明（本次新增 / 移除 / 修改了哪些）。
  • 在编辑区上方：工具栏有「提取关键线索」按钮（带放大镜图标），增量优先——只把「自上次提取以来变化的剧情段」发给 AI，省额度；首次则发全文。
  • 再次提取：会对现有线索做增 / 删 / 改的增量更新，而不是从头重写。
  • 智能提醒：当你改的剧情相对上次提取多了/少了超过约 2000 字，编辑区上方会自动提示「建议更新一次线索」。
  • 类别前缀：每条线索建议用 [类别] 前缀，例如 [人物特征] 左脸有一道旧疤、[隐患] 墙角的机关似乎通向地下。也可在文本框里手动维护。
  • 存储：线索只存在本机（创作设定层），不会进入导出的成品，纯粹是你写作的辅助手记。

▌界面说明：各个区域与按钮的作用

编辑器界面由三块组成：顶部工具栏（右上角）、中间的 文字编辑器 + 文字工具箱，以及右侧的 素材库。下面按区域介绍每个按钮的作用。

顶部工具栏（右上角）

  • 导出：把做好的游戏导出为可分享的文件（单 HTML / 标准结构压缩包 / 工程备份）。
  • 素材待办清单：列出素材库里还缺的素材（比如写了 <召唤背景:名称> 但还没上传的图）。点开可逐个补充。
  • 设置：进入设置页。AI 编剧的 API Key 与故事信息（简介 / 大纲 / 世界观 / 文风）在这里填写；关键线索文本框与提取按钮也在这里。

文字编辑器上方工具栏

  • AI：打开 AI 编剧，选择生成模式后生成、续写或扩写剧情。
  • 提取关键线索：手动触发 AI 增量提取线索（带放大镜图标，会消耗一些 Deepseek 额度）。
  • 审阅(N)：显示 / 隐藏右侧的「试玩审阅」面板；N 是当前已记录的修改意见条数。
  • 文字预览（快捷键 右 Ctrl）：快速查看文字排版与标记效果。
  • 游戏试玩（快捷键 F12）：以游戏形式试玩当前剧情；试玩顶栏有「审阅」按钮可在游玩中记修改意见。

文字工具箱

文字工具箱里是写作时最常用的插入按钮，点一下就在光标处插入对应标记：

  • 停顿（快捷键 Tab）：插入 <停顿>，玩家点一下才继续。
  • 加粗 / 斜体 / 下划线 / 删除线：分别插入 [b][/b]、[i][/i]、[u][/u]、[s][/s]。
  • 颜色：插入 [color=颜色值][/color]，给文字上色。
  • 发光：插入 [glow=颜色值][/glow]，让文字带发光效果。
  • 字号：插入 [size=数值][/size]，调整文字大小。
  • 居中：插入 [center][/center]，让文字居中。
  • 瞬显：插入 [瞬显][/瞬显]，让这段文字一次性出现而不是逐字显示。

右侧素材库

右侧素材库按素材类型分页，把里面的素材拖到文字编辑器，就会自动插入对应的召唤指令：

  • 背景库：上传背景图，或用「渐变 / 噪波生成器」生成。拖入编辑器插入 <召唤背景:名称>。上传背景图会自动弹出「图片处理面板」（见图片处理面板）。
  • 叠层库：上传透明 PNG 角色或物件。拖入编辑器插入 <召唤叠层:名称>，叠层显示在背景之上、文字之下；再次召唤会替换当前叠层，点击库顶部的「清除叠层」可插入 <清除叠层>，隐藏当前叠层并继续剧情。
  • 物品库：上传 / 导入 3D 物品（GLB 或场景包），拖入编辑器插入 <召唤物品:名称>。
  • 音乐库 / 音效库：上传音乐或音效，拖入编辑器插入对应的召唤指令。上传音频会自动弹出「音频处理面板」，可裁切多余段落、降采样率 / 转单声道压缩体积（见音频处理面板）。
  • 剧情块库：管理剧情块（默认有「主剧情」）。可切换「主剧情 / 新剧情」，用来做分支。
  • 剧情状态库：集中定义剧情状态（名字 / 类型 / 初值）。从这里把剧情状态拖入正文，会插入读取占位，并弹出浮窗选择赋值 / 增减 / 作为条件。详见剧情状态。

▌尖括号指令（< >）

尖括号指令（整行指令）

指令作用
<停顿>创建停顿，玩家点一下才会继续剧情
<标题:文字>创建一个浮动的大号文字（可以在文字部分写 BBCODE）
<分割线:文字>插入带文字的分割线；文字留空则普通横线。
<召唤背景:名称>更换背景图。
<召唤叠层:名称>显示叠层库中的透明 PNG 角色或物件；显示在背景之上、文字之下，新叠层会替换当前叠层。
<清除叠层>隐藏当前叠层，然后立即继续执行下一句剧情。该指令需要独占一行。
<召唤物品:名称>在屏幕展示可交互的 3D 物品。
<召唤音乐:名称>播放音乐
<停止音乐>让当前背景音乐渐出并停止。
<召唤音效:名称>播放音效
<选项:"按钮文字",剧情块名>在游戏底部生成选项按钮（最多 6 个），点它进入对应分支块
<选项:"按钮文字",块名,条件:表达式>带条件的选项：条件不满足时该按钮不会显示。详见剧情状态。
<变量:名=值>让剧情状态改变的高级源码写法。详见高级源码参考。
<玩家输入变量:名,"提示">弹出文本输入框，把玩家输入保存到文本剧情状态；最多 8 个字符，空提交会保留原值。
<随机跳转:块A,块B>随机进入一个剧情块；可在块名后加 =正整数 设置权重，如 块A=3,块B=1。
<随机句子:"文本A","文本B">随机显示一句文本；同样支持在引号外写权重，如 "常见"=3,"稀有"=1。
<跳回>通常放在分支块的结尾；剧情会跳回上一个剧情块并继续剧情。
<跳回重选>分支块的结尾；剧情会跳回上一个剧情块并重选选项。

!小提示：<选项:"按钮文字",剧情块名> 可以在同一行写多个，不要换行。带条件选项（条件:表达式）只在当前行内生效，不要单独换行。

分支块末尾通常以 <跳回> 或 <跳回重选> 收尾，如果没有添加 <跳回> 或者 <跳回重选>，剧情会在此结束。

▌进阶功能

下面这些功能能显著提升长篇互动剧情的写作效率与完成度：剧情状态管理、伏笔一致性（关键线索）、游玩中改稿（试玩审阅）、图片批量调色（图片处理面板）、音频裁切压缩（音频处理面板）、素材快速补齐（素材待办）。

游玩体验与存档

  • 长文 / galgame 模式：在「设置 → 外观」切换。长文模式会累积并滚动显示文字；galgame 模式每段文字显示在底部文本框中，停顿、分割线、标题和选项都会开启新段。
  • 自动播放与历史：成品顶部可开启自动播放（每次停顿约 2.5 秒后继续），也可打开「历史」回看本次游玩中已读的文字。
  • 存档 / 读档：成品支持多个本地存档槽；在支持的平台中会尝试同步云存档。存档会保存当前剧情位置、已选分支、背景音乐与剧情状态。
  • 外观：可设置开场背景和音乐、水印、文字对比度、字体与字号、标题颜色，以及 galgame 文本框透明度。

分支、随机与玩家输入

  • 剧情块管理：剧情块支持新建、复制、改名和删除；改名会同步更新选项和跳转引用。拖动剧情块时，可选择插入选项或直接跳转。
  • 分支图：可打开剧情分支图查看剧情块、选项和随机跳转之间的关系，方便检查分支闭环。
  • 随机指令：<随机跳转> 用于随机分支，<随机句子> 用于随机文案；两者的权重均为正整数，缺省权重为 1。
  • 玩家输入：先创建文本剧情状态，再使用输入功能收集昵称、答案等内容；后续正文可显示这份剧情状态。

素材、3D 与发布

  • 图片与叠层：背景和叠层支持 PNG、JPG、WebP、GIF 等图片；GIF 默认归入叠层库。背景与叠层之间可以互移或复制，引用会同步改写。
  • 3D 物品：导入 GLB 或场景包后，玩家可在成品中检视物体；可把结束物体绑定到指定剧情块，触发后进入该分支。场景包携带的视角与 HDRI 环境设置会随成品保留。
  • 素材处理：图片处理面板可生成或调整背景；音频处理面板可裁切、压缩和转码音频。素材待办会汇总脚本中已引用但尚未导入的素材。
  • 导出与 Toy 发布：可导出单 HTML、可修改的标准结构压缩包或工程备份；「设置 → Toy 发布」可导出单文件成品并打开 B 站 Toy 上传页。

剧情状态：让选择记得玩家做过什么

剧情状态会记住玩家一路上的收获、关系和决定。你只要在右侧素材库建立一个状态，再用可视化编辑里的「条件」和「变化」把它连进选项；不需要先会写源码。

五分钟快速入门

先做一个最小的互动：玩家攒够 10 金币，就能在商店买一把钥匙。

可视化工作流

1. 在「素材库 · 剧情状态」新建剧情状态「金币」，类型选数字，初值填 10。

2. 在「剧情块库」新建「商店」和「拿钥匙」两个剧情块。

3. 切到编辑器上方的「可视化编辑」，点要修改的选项，填入：按钮文字「花 10 金币买钥匙」→ 目标剧情块「拿钥匙」。

4. 点「添加条件」，选择「金币」，设为「不少于 10」；再点「添加剧情状态变化」，选择「金币」→「减少」→ 填 10。

完成：玩家金币不足时看不到购买按钮；买到钥匙后金币会自动扣除。点「游戏试玩」即可验证。

!每个剧情状态都先在「素材库 · 剧情状态」建立。这里是唯一的资料来源；需要检查旧稿时，点上方「修复检查」。

金币与商店

数字类型适合金币、生命和线索数量。让奖励选项增加金币，让购买选项设置门槛并减少金币；同一个选项可以同时改变多个剧情状态。

好感度与分支

为角色建立数字类型的「好感度」。在关键选项添加条件，例如「好感度不少于 3」，就能让信任路线只在关系足够时出现。

钥匙状态

开关类型适合「已拿到钥匙」「陷阱已触发」这类只有是或否的事情。拿钥匙的选项把状态设为「真」；开门选项要求它为真。正文也可以用可视化插入的状态文字，向玩家说明门是否已打开。

玩家姓名

文本类型适合昵称、暗号和玩家回答。先建立「名字」，再使用可视化编辑中的输入步骤收集称呼；之后在正文插入这个剧情状态，故事就会显示玩家输入的名字。

多条件路线

一个选项可以放多条条件。选择「全部满足」时，玩家需要同时带着钥匙、拥有足够好感度；选择「任一满足」时，满足其中任意一条即可。先把路线用日常语言写清楚，再逐条填入，最不容易出错。

旧项目转换

旧项目仍可继续用源码模式编辑。想改用可视化编辑时，在项目列表选择「转换为可视化项目」：编辑器会复制一份新项目，原项目保持不变。转换后先试玩关键分支，再逐步改写即可。

高级源码参考

这一节只给需要手写或维护旧稿的人。源码中把「剧情状态」称为变量：变量的唯一权威仍是素材库 · 变量库，先在这里定义，再在正文引用。

① 定义变量

右侧素材库切到 变量库 tab → 点「＋ 新建变量」，填三项：

  • 名字：唯一标识符，正文用 {名字} 读取（只能含中文 / 英文 / 数字 / 下划线）。
  • 类型：数字 / 布尔（真或假）/ 文本。类型决定它能做什么：数字能加减和比较大小，布尔用于开关判断，文本只能显示和被玩家输入覆盖。
  • 初值：游戏开始时的默认值。

② 读取变量（写在正文中）

你的金币是 {金币}。
门的状态：{解锁:已开门|还没开}
  • {金币}：直接替换为当前数值 / 文本；布尔变量显示「真」/「假」。
  • {解锁:已开门|还没开}：仅布尔变量可用，真显示「已开门」、假显示「还没开」（中文冒号分隔）。
  • 未定义的变量会原样保留不替换；写 {{金币}}（双花括号）可转义，显示字面 {金币}。

③ 修改变量（整行指令）

<变量:金币=10>
<变量:生命-3>
<变量:解锁=true>
<变量:金币=10;生命-1>
<变量:a=1><变量:b=2>
<变量:台词=你好 世界>
  • = 赋值；+N / -N 做增减，仅对数字类型有效（编辑器会检查并对非数字加减给出提醒）。
  • 赋值时值可以包含空格、也可以留空：<变量:台词=你好 世界> 存入「你好 世界」，<变量:名字=> 存入空字符串。写 true / false 会存成布尔，纯数字存成数字，其余按文本处理。
  • 一行可写多个操作：每个 <变量:…> 标签一个操作（如 <变量:a=1><变量:b=2>），也兼容老版本在单个标签内用分号分隔的写法 <变量:金币=10;生命-1>。
  • 这些指令独占一行，执行时不显示任何文字，只改变变量值。无法识别的 <变量:…> 行会按普通文本保留（导出与编辑器行为一致），修复检查会帮你把它们找出来。
  • 便捷插入：从变量库把变量拖入正文，会自动插入 {名字} 读取占位，并弹出一个小浮窗供你选「赋值 / +1 / -1 / 作为条件」——选好即生成对应指令。

④ 选项条件（让按钮按需出现）

给选项加 条件:表达式，只有条件成立时按钮才渲染；不成立则玩家完全看不到这个选项（一行内所有选项都不满足时自动跳过该行继续推进）。

<选项:"用钥匙开门","开门块",条件:钥匙==true>
<选项:"贿赂守卫","密道块",条件:金币>=50>
<选项:"强攻","战斗块",条件:力量>=20 && !警觉>
<选项:"谈判","谈判块",条件:(声望>=10 || 金币>=100) && !被通缉>

条件表达式支持：

  • 比较运算符：>= <= == != > < =（旧写法 = 等价 ==）。字符串值请加引号：条件:状态=="变身"。
  • 逻辑运算：&&（且）、||（或）、!(非)，支持括号分组。优先级为 ! 高于 && 高于 ||——a&&b||c 按「(a 且 b) 或 c」计算。
  • 布尔直接写变量名即「为真」：条件:钥匙 等价于 条件:钥匙==true；条件:!陷阱 表示「陷阱未触发」。
  • 语法错误（如括号不配对、缺操作数）会在校验和修复检查中提示，不会静默算错。

!小提示：用浮窗选「作为条件」时，工具会自动把当前变量拼成 ,条件:变量名 追加到光标所在那行的选项里——所以要先确保光标在 <选项:…> 这一行。

只在满足条件时改变变量

<选项:"鼓起勇气购买",商店,条件变化:(勇气>=1)=>金币-10>

变化: 每次选中都执行；条件变化: 只在括号条件成立时执行。同一选项的多条变化条件均按点击选项前的变量状态判断。

⑤ 修复检查：排查全部剧情块的变量问题

入口：素材库 → 变量库 → 「修复检查」按钮。它会一次性扫描主剧情和全部剧情块，跨模块汇总问题：

  • 未声明赋值（错误）：正文里 <变量:金帀=5> 但变量库里没有「金帀」——多半是错别字。提供两个一键修复：「创建该变量」或「改名为相似的正确变量」（如金帀 → 金币，改名会同步更新所有剧情块里的引用）。
  • 未定义读取 / 条件引用（提醒）：用了 {某变量} 或在条件里引用了未定义的变量。
  • 坏指令（错误）：<变量:…> 格式不对，可一键删除该指令。
  • 条件异常：空条件或无法解析的表达式。
  • 类型混用（提醒）：如对文本变量做 +1、对非布尔变量用 {名:真|假} 显示映射。
  • 建议类：从未被赋值的变量（永远等于初值）、赋了值但从不读取的「死变量」。

每个问题都标注所在剧情块和行号，点「定位」直接跳到那一行；「忽略」仅本次会话生效。预览 / 导出前的编译检查也会展示其中的错误与提醒。

关键线索：保持伏笔一致

详见上方 AI 功能 · 关键线索提取。小结：

  • 入口有两处：设置 → AI编剧（带变更说明）与 编辑区上方「提取关键线索」（增量优先、省额度）。
  • AI 把线索归为 9 类，建议用 [类别] 前缀书写，例如： [人物特征] [人物性格] [人物创伤] [未解角色] [未使用物件] [强力物件] [未解事件] [重大影响事件] [隐患]。
  • 每次提取都是增量增删改，结果是完整清单；正文改动超过约 2000 字会自动提示更新。
  • 线索只存本机（创作设定），不进导出成品。

试玩审阅：边玩边记修改意见

写稿时你常常需要在「游玩体验」和「改稿」之间反复横跳。审阅功能让你在试玩过程中，随时把「这一句想改什么」记下来，回到编辑器就能看到。

  1. 点编辑器上方「游戏试玩」（或 F12）打开游戏，试玩顶栏（iframe 外）最显眼处有一个 审阅 按钮。
  2. 玩到任意一句剧情，随时点 审阅 → 工具自动取出「当前正在显示的剧情片段」作为上下文 → 弹出输入框。
  3. 在框里写修改意见（必填），可顺带带上那句剧情的片段做引用 → 点 保存。
  4. 保存后：
    • 编辑器右侧「审阅」面板自动展开，按剧情块分组列出每条意见；引用片段带红色波浪下划线，意见本身橙色底，含时间、跳转（点卡片跳到对应块）、删除。
    • 主编辑器当前块下方出现一条红色虚线标记「此块有审阅意见」。
    • 编辑器头部「审阅(N)」开关显示待处理条数角标，点它可收起 / 展开右侧面板。
  5. 之后回到编辑器改稿、再试玩、再补意见都行。

!小提示：审阅记录只存本机，不会进入发布的成品（单 HTML / zip 不含这些意见），纯属你的写作辅助。红线是「块级标记」（当前块下方一条红线），右栏里的引用片段才是逐字红波浪下划线。

图片处理面板：上传即调色

你喜欢的后处理效果（像素感、压缩体积）现在做成了可调界面：每次上传背景图都会自动弹出处理面板，参数全可调，满意了再入库。

触发方式：以下任一路径都会弹出面板——

  • 素材待办里点上传 / 拖文件 / 悬停行 Ctrl+V 贴图；
  • 背景库「导入」按钮、或把图片拖进背景库；
  • 若一次上传多张，会一张张依次弹出。

面板里有什么：

  • 并排预览：左「原图」、右「处理后」（像素硬边显示，方便看像素感），下方显示输出体积 + 尺寸。
  • 分辨率下拉：原始 / 360 / 540 / 720（默认）/ 1080 / 1440（按高度等比缩放）。
  • 颜色级数滑块：2–64 级（即像素量化的色数）；旁边有「像素量化」开关——关掉就保留原色。
  • 亮度 / 对比度 / 饱和度三个滑块（−100~100）。
  • 平滑缩放开关：关掉就是像素硬边放大。
  • 格式下拉 JPEG / PNG；选 JPEG 时还能调质量滑块（0.4–0.95）。
  • 底部按钮：重置（回到默认、也就是你喜欢的那个效果）、用原图（完全不处理）、取消、应用并保存。

!小提示：拖动任意滑块，右侧预览会实时刷新（已做防抖），边拖边看；应用后背景库自动切到「背景库」tab 并显示新缩略图。默认参数刻意设成和旧版自动处理一致，所以「应用」即原效果，只有想改时才动手。

音频处理面板：导入即裁切 + 压缩

音乐 / 音效文件往往很大，现在导入时会自动弹出处理面板，可以裁掉多余段落、降采样率 / 转单声道来压缩体积，全程在浏览器本地完成，不会上传到任何服务器。

触发方式：从音乐库 / 音效库的「导入」按钮、或把音频文件拖进素材库，都会弹出面板（多张依次弹出）。

面板里有什么：

  • 波形预览：显示整段波形，并用蓝色高亮标出当前裁切区间；下方实时显示「时长 · 采样率 · 声道 · 预估体积」。
  • 裁切起点 / 终点两个滑块：拖动即可选取要保留的片段（比如剪掉歌曲前奏或尾噪）。
  • 采样率下拉：原始 / 44100 / 32000 / 22050 / 16000 / 11025 Hz——调低能显著减小体积。
  • 声道：立体声 / 单声道（单声道再省一半）。
  • 格式：MP3（体积小，本地 lamejs 编码）/ WAV（无损）；选 MP3 时可调码率 96 / 128 / 192 kbps。
  • 试听片段：在处理前先听一下当前裁切 + 压缩后的效果。
  • 底部按钮：重置（回到默认：全段 + 原始采样率 + 立体声 + MP3 128）、用原文件（完全不处理直接入库）、取消、应用并保存。

!小提示：最省体积的组合是「裁掉多余长度 + 采样率 22050 + 单声道 + MP3 128」，一段 5 分钟的立体声音乐能压到原来的几十分之一。如果浏览器不支持某格式（极少见），面板会自动回退成 WAV 并提示。

素材待办：缺素材也能先写完稿

当你写了 <召唤背景:名称> 等召唤指令、却还没上传对应素材时，文字编辑器右上角会出现「素材待办」按钮。点开后是按素材类型列出的待补全清单，每条带名字和即时预览位。

几种补齐方式：

  • 逐行上传 / 拖文件：在待办面板里点某行上传，或直接把图片 / 文件拖到那一行。
  • 悬停 + 粘贴图片：鼠标悬在某条背景待办行上，按 Ctrl+V（或右键粘贴）即可把剪贴板里的图片上传进去——支持截图、右键复制的网络图等。焦点在哪都无所谓，只要鼠标悬在那一行。
  • 上传后自动刷新：背景图上传成功，背景素材库会自动切到「背景库」tab 并刷新，新图立刻显示。
  • 该行约 1.6 秒后因「已补齐」自动从待办消失。

!小提示：推荐工作流——先一口气把文本和所有召唤指令写完（名字随便编），再统一开「素材待办」一条条补，效率最高。
