# 示例冒险项目

这是一个用来展示「剧情编辑器」核心功能的示例冒险故事。

## 包含的资源

- `assets/atlasaudio-adventure-518065.mp3` —— 主题曲（上传到音乐库，命名为 **主题曲**）
- `assets/Clipboard_Screenshot.png` —— 冒险开始场景图（上传到图片库，命名为 **冒险开始**）
- `assets/Clipboard_Screenshot-1.png` —— 打史莱姆场景图（上传到图片库，命名为 **史莱姆平原**）
- `story.txt` —— 完整剧情文本

## 展示的功能

- `<召唤音乐:主题曲>` —— 循环播放背景音乐
- `<召唤背景:冒险开始>` / `<召唤背景:史莱姆平原>` —— 切换全屏背景
- `@image#1:Clipboard_Screenshot.png` / `@image#2:Clipboard_Screenshot-1.png` —— 正文内嵌图片
- `<标题:...>` —— 浮动大标题
- `/// 第一章：冒险开始` —— 左侧大纲的大章节导航
- `<变量:勇气=1>` / `{勇气}` —— 变量赋值与读取
- `<停顿>` —— 点击后继续
- `<停止音乐>` —— 停止背景音乐

## 如何使用

1. 打开编辑器（[在线使用](https://jigugumiao.github.io/jiji_text_game_editor/) 或本地 `index.html`）。
2. 右侧「图片库」上传两张 PNG，分别命名为 **冒险开始** 和 **史莱姆平原**。
3. 右侧「音乐库」上传 MP3，命名为 **主题曲**。
4. 把 `story.txt` 的内容复制到文字编辑器中。
5. 点击右上角「试玩」即可体验。

> 提示：编辑器首次新建项目时，主剧情会自动填入一段精简版示例文本，源码位于 `js/editor.js` 的 `DEFAULT_TEXT`。
